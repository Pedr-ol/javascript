## 📚 Conteúdos

Os códigos deste repositório foram desenvolvidos para praticar os principais conceitos da linguagem JavaScript, desde fundamentos até a interação com páginas web.

### Principais conceitos

- Variáveis e constantes;
- Tipos de dados;
- Operadores;
- Estruturas condicionais;
- Estruturas de repetição;
- Funções;
- Arrays;
- Objetos;
- Manipulação do DOM;
- Eventos;
- Interação com páginas HTML;
- JavaScript no desenvolvimento web.

## 💻 Tecnologias

- **JavaScript**
- **HTML5**
- **CSS3**

## 🎯 Objetivos

- Desenvolver fundamentos de programação utilizando JavaScript;
- Compreender a sintaxe e os principais recursos da linguagem;
- Praticar estruturas de decisão e repetição;
- Criar e utilizar funções;
- Trabalhar com arrays e objetos;
- Manipular elementos HTML através do DOM;
- Utilizar eventos para criar páginas interativas;
- Aplicar JavaScript em projetos web.
